# 裝修設備規劃｜去識別化公開示例

這是一份可閱讀、可編輯的室內裝修規劃示例：保留圖面量繪的房間輪廓、門窗、物件標位、商品與歷史工程報價，移除私人住址、客戶身分與可辨識的廠商名稱。**原工程報價基準為 NT$1,959,530**；後續選款、增減項與待報價設備另行試算。金額是特定情境的歷史估價，**不是現行有效報價**；圖面和照明模擬僅供討論，**不得作為丈量圖、施工圖或電氣設計**。

## 離線開啟

1. 下載 [`portable/裝修設備規劃.html`](portable/裝修設備規劃.html) 與 [`files/設備規劃.json`](files/設備規劃.json)，放在自己的電腦上。
2. 用最新版 Chrome 或 Edge 雙擊 HTML，按「**讀檔 JSON**」選擇示例存檔。可瀏覽房間與門窗示意、拖放設備、修改商品、試算價格，並輸出清單 CSV。
3. 修改後按「**存檔 JSON**」取得新版存檔；瀏覽器的本機暫存不能代替存檔。離線 HTML **不內嵌**設備 JSON，首次開啟須自行讀入；不需要伺服器或網路。

示例 JSON 是 **v5**，含 13 個空間、179 個物件與 18 款商品；原有匿名物件 ID 與商品連動均保留。修訂版次為 0、`undo` 為 `null`，未附先前編輯紀錄。日後自己匯出的 JSON 可能包含新輸入的私人資料與單步復原點，分享前請另行檢查。

## GitHub Pages 線上預覽

<https://zero0415.github.io/house_design/> 從 `main` 分支的 `/(root)` 進入同一份互動規劃器。這個首頁帶有明確的示例參數：**僅在 HTTP(S) 網頁且此瀏覽器沒有已儲存資料時**，規劃器才會從本站 `files/設備規劃.json` 載入當前去識別化示例；已有編輯紀錄時絕不以新示例覆蓋。示例無法載入時會提示錯誤，仍可按「讀檔 JSON」手動匯入。直接開啟離線 HTML（包括 `file://`）仍須自己讀入 JSON，程式不會對外下載示例。

**Pages 上的修改只存於你自己的瀏覽器，不會更改 GitHub 儲存庫，也不會同步到其他裝置。**請定期按「存檔 JSON」下載備份；清除瀏覽器暫存後，沒有匯出的修改無法復原。先前已儲存的瀏覽器資料會優先於新版示例，欲檢視新版可使用另一個乾淨瀏覽器／無痕視窗，或先匯出個人資料再自行決定如何處理暫存。網頁只向本站讀取示例資料，不會自動向第三方網站請求商品資訊。

## 廚房與去識別化電源標位

新示例另收錄 **12 個可移動的廚房櫃體／設備概念圖例＋1 筆未標位下嵌工資**，以及 4 款有參考價的廚房商品：JT-690 水槽 NT$4,700、龍頭 NT$3,000、排油煙機 NT$6,400，與 3M IH1000 櫃下即熱飲水機 NT$35,900；工資 NT$1,500，已知追加合計 **NT$51,500**。飲水機價格由情境資訊提供，尚未獨立驗證；Bosch 洗碗機、各櫃體及兩個放在**同一個 80cm 爐檯**的獨立 IH／瓦斯單口爐仍待選型與報價。60／76／80cm 主排是概念圖，並非可施工尺寸；原工程報價 NT$1,959,530 **不變**。

另一份原始電源配置文件只轉錄獲准公開的點位類別與比例座標：**51 個紅色 R 一般電源＋9 個黑色 B 獨立實體專用供電端點＝60 個電源**，另有 **7 個綠色 C 弱電／網路埠（不是電源）**。9 條專用迴路各配一個 B 端點，迴路圖示不是第二顆電源；原報 50 電源 × NT$1,800、7 迴路 × NT$4,500 與弱電 7 條 × NT$3,000 仍是歷史基準。現方案的數量相對原報額度暫增 **NT$27,000**；弱電額度不再加 21,000。綜合其餘已知規劃項目，示例顯示的暫計總額為 **NT$2,107,948**，不是全工程最終報價，未報商品與施工費仍未計。

R08（客餐廳凹角）、R33（陽台水槽旁）、R42（主臥弧牆外）保留來源標位並有橙色衝突警示，**不自動移入屋內**；B05 電器櫃電源在左，廚房概念高櫃在右，供電路徑同樣待核。B02–B04 暫列臥室3外牆側，歷史 ID 不代表已確定供應哪台冷氣。圖示／CSV／JSON 是待現勘資料，不能當插孔型式、電壓適用性、濕區防護或施工核可。

## 衛浴安裝與房間切換

原水電報價「衛浴設備安裝」**2 套 × NT$8,000＝NT$16,000** 已含在 NT$1,959,530 基準。兩浴**原有馬桶、面盆／浴櫃、面盆龍頭與淋浴**各四筆，加上**主浴小便斗、客浴浴缸**，共 10 筆一般衛浴器具；其商品本體單價照原規劃保留（未知仍待報），安裝單價標記 **NT$0（原報已含）**，不把原 16,000 元逐件重複加到規劃總額。清單、JSON 及 CSV 的「安裝小計（新台幣）／安裝費來源」會明示 0 與報價來源；舊 v5 存檔匯入時會補足這十筆的零額度，不改商品價、物件或其他設備。新增小便斗的感應供電、浴缸加大後的改管及超出原安裝範圍的施工補差仍須廠商另核；**免治便座、新風機、電熱毛巾架、防滑扶手與其他新增配件／電路不自動視為已含**。

在「格局圖」選房間後，房間頁上方以**藍色「← 返回全屋格局」按鈕**回全屋，以另一側「切換房間 · 目前：房間名稱」下拉直接切換房間；這兩個操作只換檢視，不會修改存檔或報價。示例規劃後暫計為 **NT$2,107,948**。

## 報價與參考圖

[`files/裝修工程報價-去識別化.md`](files/裝修工程報價-去識別化.md) 保留原報價的分類、數量、單價、合計及施工說明；個人地址、廠商身分與可辨識門片品牌已省略。標示「未計入」的品項不是免費，仍須請合格人員重新估價與現勘。商品型號與商店連結是參考資料，程式不會自動向外部網站請求資料。

**沒有發布原始工程／電源配置 PDF、設計掃描、廚房附件圖片或其像素／中繼資料。**「門窗尺寸示意」、兩張對照圖及「規劃幾何底圖」都由 [`house-geometry.js`](extensions/renovation-equipment/assets/house-geometry.js) 的座標與規劃器的 SVG 繪製邏輯重新產生；新廚房參考與 R/B/C 點位也只使用新寫的向量元素及去識別座標，不是在原始圖片上覆蓋遮蔽層。示意圖含規劃新增隔間，W／DH 尺寸由原始標註轉寫，實際牆厚、門窗淨空、外推承重與設備安裝條件都尚待核實。房間幾何、電源點位與價格仍具情境獨特性；請先審閱再轉發。

## 原始碼與重建

`extensions/renovation-equipment/assets/` 是共用的規劃器介面及幾何／預算邏輯，`extensions/renovation-equipment/state.mjs` 負責驗證存檔；`tools/portable-bootstrap.js` 將相同模組接入瀏覽器本機儲存。`extensions/renovation-equipment/extension.mjs` 是在提供 `@github/copilot-sdk/extension` 的 Copilot App 環境中使用的可選畫布入口，不是離線使用的必要條件。

在此目錄執行 `python tools\build_portable.py` 即可用 Python 標準函式庫重建 [`portable/裝修設備規劃.html`](portable/裝修設備規劃.html)；建置會拒絕靜態圖片或 PDF 參照，不讀取原始文件。執行 `python -m unittest discover -s tests -v` 可檢查公開存檔、報價基準與單檔產物。若已安裝 Chrome 和 Python Playwright，可先在 PowerShell 設定 `$env:RUN_PAGES_BROWSER_TESTS = "1"`，再執行同一測試指令；測試會用本機 HTTP 伺服器模擬 Pages 子路徑、存檔衝突及離線行為。公開版不附原始文件、個人檔案或任何私人儲存庫的 Git 歷史。
